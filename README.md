# NOX NEXT

منصة اجتماعية عربية بهوية بصرية موحدة للكمبيوتر والهاتف.

## المرحلة الأولى — الواجهة الرئيسية
- واجهة رئيسية مستوحاة من التصميم المرئي المعتمد.
- شريط جانبي للكمبيوتر وشريط سفلي للهاتف.
- حالات، منشور تجريبي، مربع إنشاء منشور، قائمة أبرز الأصدقاء، وبطاقة NOX KISS.
- فصل منطق التنقل والمظهر وتهيئة التطبيق داخل مجلد core.

## هيكل الملفات
- `index.html`: هيكل الواجهة.
- `styles.css`: الهوية البصرية والتجاوب مع الشاشات.
- `app.js`: نقطة الدخول.
- `core/navigation.js`: التنقل.
- `core/theme.js`: إعداد المظهر.
- `core/app.js`: التفاعلات الأولية.

## توضيح الحالة
هذه واجهة أمامية تجريبية. الصور والأسماء والأرقام المعروضة بيانات شكلية وليست حسابات حقيقية. البحث والنشر والتعليقات والمحادثات وقاعدة البيانات غير مفعّلة بعد. زر NOX KISS يفتح النموذج التجريبي الموجود.

## الأمان
لا تضع كلمات مرور أو مفاتيح API سرية في ملفات المتصفح. يجب تنفيذ التحقق والصلاحيات في الخادم قبل إطلاق أي وظائف حقيقية.

## أقسام NOX NEXT الموسعة
- اكتشف: تصنيفات ومحتوى استكشافي.
- الأصدقاء: واجهة البحث بمعرّف NOX ID واقتراحات الأصدقاء.
- الإشعارات: مركز التنبيهات.
- المحفوظات: قائمة المنشورات المحفوظة.
- الهدايا: كتالوج هدايا رمزي تجريبي.
- الإعدادات: تفضيلات عرض وخصوصية أولية.
- إنشاء منشور: نافذة نشر مع اختيار جمهور المنشور وتفاعلات إعجاب وحفظ.
- قائمة «المزيد» على الهاتف للوصول إلى الأقسام الإضافية.

## حدود النسخة الحالية
الأقسام والتفاعلات الجديدة هي طبقة Frontend تجريبية تعمل داخل جلسة الصفحة فقط. لا يتم إرسال منشورات أو طلبات صداقة أو رسائل أو هدايا إلى مستخدمين آخرين، ولا توجد مدفوعات. البحث العام عن الأعضاء، مزامنة المنشورات، الإشعارات الفورية، الرسائل، وحفظ البيانات بين الأجهزة تتطلب إعداد قواعد بيانات Appwrite وصلاحياتها وخدمات الخادم قبل تفعيلها.


## حالة محرك الكاميرا الحالية
- يتضمن مسار الكاميرا تشغيل بث المتصفح، تبديل الأمامية/الخلفية، عرض WebGL مع بديل Canvas 2D، التقاط الصور، وتسجيل الفيديو عند دعم المتصفح للواجهات المطلوبة.
- توجد مكتبتان منفصلتان: كتالوج 340 إعدادًا بصريًا في 17 مجموعة، ومكتبة NOX ORIGINAL الإجرائية ذات 1,000 وصفة. لا تعني الأعداد وجود 1,340 خوارزمية أو تأثيرًا دلاليًا مستقلًا.
- تتبع الوجه الهندسي وتحليل نقاط الوجه عبر MediaPipe متاحان كمسارات اختيارية. مكياج NOX BEAUTY VISION الدلالي الحالي محدود بالشفاه والحواجب؛ لا توجد أقنعة مستقلة للخدود والجفون أو فصل شعر/خلفية عام.
- سجل المحركات يكتشف نسخ المحركات التي أنشئت وسُجلت أثناء التشغيل، ولا يمسح ملفات المشروع تلقائيًا. مخطط التشغيل والـ Scheduler يقدمان قرارات أهلية وتشخيصًا؛ لا يشغّلان كل المحركات أو يغيران مسار الرسم تلقائيًا.
- الاختبارات الآلية تعمل مباشرة عبر Node.js وGitHub Actions؛ لا يوجد package.json أو npm test script في الجذر. نجاح CI لا يثبت جودة الصورة أو الأداء على هاتف فعلي.
- لم يتم اعتماد اختبار ميداني على Android/iOS حتى الآن. يلزم اختبار Android Chrome، خصوصًا على الأجهزة منخفضة الإمكانيات، قبل وصف الكاميرا بأنها جاهزة للإطلاق.

## المعاينة والنشر
- ملف `.github/workflows/preview-pages.yml` الحالي يستمع إلى الفرع `feature/appwrite-auth` وليس فرع الكاميرا.
- هذا المسار يستخدم GitHub Pages في المستودع نفسه؛ لذلك لم يتم تحويله تلقائيًا إلى فرع الكاميرا حتى لا يستبدل موقع Pages المنشور بدل إنشاء معاينة معزولة.
- لا تعتبر نسخة الكاميرا منشورة أو متاحة للاختبار العام إلا بعد إنشاء وجهة معاينة منفصلة والتحقق من رابط نشر حقيقي.
