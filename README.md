# NOX NEXT

منصة اجتماعية وترفيهية عربية، بتصميم Mobile First وواجهة RTL.

## مبادئ المشروع
- بناء جديد من الصفر، دون الاعتماد على مشاريع سابقة.
- بنية معيارية بسيطة قابلة للتوسع.
- عدم وضع مفاتيح API أو كلمات مرور أو أسرار في ملفات الواجهة أو المستودع.
- البدء بإصدار تجريبي آمن وبلا مدفوعات حقيقية.
- نقاط NXC في النسخة التجريبية افتراضية فقط، وغير قابلة للشراء أو السحب أو التحويل إلى أموال.

## الوحدات المخطط لها
- NOX ID: الحسابات والملفات الشخصية.
- NOX CHAT: المحادثات والوسائط.
- NOX LIVE: المكالمات.
- NOX STATUS وNOX REELS: الحالات والمقاطع القصيرة.
- NOX KISS: لعبة اجتماعية ترفيهية.
- NOX GIFTS: الهدايا الافتراضية.
- NOX ADMIN: أدوات الإدارة والإشراف.
- الأمن والمراقبة والنسخ الاحتياطي وسجل التدقيق والتحكم بالميزات.

## البنية الأولية
سيتم تثبيت قرارات البنية بعد التحقق من حدود الخطط المجانية وإعدادات المشروع. لا تُدرج أي أسرار في هذا المستودع.
